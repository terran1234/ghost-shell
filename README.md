# 과제 2 — 내가 설계한 미니게임: Ghost Shell

브라우저에서 실행되는 CLI 스타일 해킹 타자 게임입니다. 로그인 없이 아래 링크로 바로 플레이할 수 있습니다.

## 결과물 주소
https://claude.ai/artifact/3gsRptaJpfH7pDeWyFxiUe

## 소스
이 저장소의 `ghost-shell.html` (단일 파일, HTML/CSS/JS)

## 짧은 확인 방법
- 위치: 결과물 링크 접속 → 미션 브리핑 화면
- 행동(3단계 이내): ① Space 또는 클릭으로 임무 시작 → ② 화면에 뜨는 문자열을 키보드로 입력 → ③ 30초 제한시간 내 3단계(정찰→침입→흔적삭제)를 모두 클리어
- 통과 모습: "ACCESS GRANTED" 화면과 함께 보수 지급 연출이 뜬다
- 실패 모습: 제한시간 초과 또는 탐지율 100% 도달 시 "TRACED" 화면이 뜨고, Space/클릭으로 즉시 재시작된다

## AI와 나의 판단
- AI에게 맡긴 일: 게임 로직 구현(충돌·타이핑 판정, 난이도 곡선), UI/CSS, 저장·복구 코드, 버그 원인 조사(z-index, 포커스, IME, 캐시)
- 직접 판단한 일: 장르·소재 선정(실제 침투 방법론 단계 순서 차용), 난이도 값 하나만 비교하는 실험 설계, UI 톤(미니멀 CLI, 메신저 연출) 방향 결정
- AI 제안을 따르지 않은 일: 초기 네온/배경 이미지 연출을 실제 CLI 느낌에 맞지 않는다고 판단해 순정 검정 배경으로 되돌림
